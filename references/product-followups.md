# 商品详情、比较与链接研究

本参考只在用户基于最近候选追问详情/比较，或提供筛电商品链接研究相似、更便宜款时读取。不用于首次搜索和推荐。

## 1. 商品身份

- “第一款/第二款/最后一款”指最近一次可见候选顺序。每次新搜索结果会替换这个顺序。
- 上一轮没有实际展示候选或可见数量不足时，不执行 lookup 或新搜索；明确说明对应的第一个、第二个等候选不存在，因此当前无法比较。
- SPU、SKU、图片、名称、价格、规格、详情链接和编号是不可拆分元组。详情链接只能逐字使用该商品的工具返回值，不手写、拼接、解码、删参数或借用。
- 用户询问多个未编号同类商品而无法唯一对应时，只问一个问题请其指定。
- 正文不显示或解释 `sku_id`、`skuId`、`goodsId`、`spu_id`；它们只可保留在工具原样返回的链接目标中。

## 2. 查看最近候选详情

用户只查看最近候选中某一款时，优先逐字执行上一次 finalize 结果的 `selection_command`，只把 `<候选编号>` 替换为用户所指编号。脚本会输出比首轮单个候选块更完整的信息：原候选事实、进一步推荐说明、当前选中规格和价格、库存状态、其他可选规格，以及搜索结果真实提供的成分、功效、适用信息、用法、净含量、包装和生产参数。

把返回的 `response.markdown` 从第一个 `#` 开始逐字作为唯一回复，不缩写、不改写链接。`selection_command` 不存在或状态已过期时，才用真实 SKU 回查；回查失败就说明当前暂时无法取得可靠详情，不沿用旧链接或构造新链接。

## 3. 比较与回查

- 回查或比较多个候选时，用同一次 `search-tools lookup --ids <first_sku_id>,<second_sku_id> --json`，不逐个调用。
- 回查后保持上一轮编号和商品身份；只在用户明确改变条件后重新排序。
- 比较只覆盖用户关心且有证据的维度；未知写“商品信息未注明”，不用默认分数伪装证据。
- 每个点名商品必须在紧邻位置显示自己的完整 H5 详情链接；没有可靠绑定链接就不点名。

## 4. 商品链接研究与相似/更便宜款

用户给出筛电商品详情链接时：

完整阅读本参考后，下一个工具调用必须是第 1 步的 lookup。不得列目录、检查或读取 `scripts/`、`assets/`，也不要再读取商品搜索参考；后续 search 返回的 `model_task`、`prepare_command` 和 `finalize_command` 已包含完成两阶段推荐所需信息。

1. 第一个工具调用只执行一次 `search-tools lookup --product-ref "<原链接>" --json`，取得原商品真实标题、规格、价格、SKU 和 H5 链接。`<原链接>` 必须从用户消息逐字复制完整字符串；调用前逐字符核对，尤其不得漏写、调换或凭记忆重输数字标识。
2. 若用户还要更便宜或相似款，第二个工具调用只执行一次 `search "<原商品完整标题 + 用户条件>" --json --agent-response`。用户要求总价“更便宜”时，必须把 lookup 返回的原商品价格转成严格预算条件并写入查询，例如原价为 59 元就加入“总价低于 59 元”；不得只写“更便宜”而让后续模型自行过滤。这样由搜索阶段统一排除原价及更贵商品。
3. 原商品至少一次逐字显示 lookup 返回的完整 title；紧邻位置逐字复制其规格、价格和 H5 `detail_url`。
4. 候选名称和链接分别逐字使用同一结果项的 `name` 和 `detail_url`；不手写、改字、缩短或重新编码。
5. lookup 返回的原商品名称、规格、价格、SKU 和 `detail_url` 是只读元组，后续 search 返回的同商品字段不得覆盖；尤其不得用后续渠道化链接替换 lookup 的原始 `detail_url`。
6. 原商品单独展示，不属于“更便宜的相似款”；搜索结果中与原商品 SKU 相同的项目必须排除。
7. 用户要求“更便宜”时，候选总价必须严格小于原商品总价。同总价的大规格只能在用户明确接受“单位价格更低”或“性价比更高”时展示，不能称为更便宜。
8. lookup 或 search 没有足够事实时立即使用错误或无结果回复，不读取脚本、不重复调用、不自行构造链接。
9. 没有严格更便宜且有相似性证据的候选时，只展示原商品只读元组并说明未找到；不点名、不比较被价格或证据条件排除的商品，避免把无链接的非候选带入正文。

对于同时含 `goodsId` 和 `skuId` 的合法筛电移动端详情链接，包装脚本会在内部按规格标识回查目录，并重新绑定到用户提供的完整原链接。模型不拆参数、改用商品标识、重复 lookup 或自行测试链接。

不执行 Web 搜索来补商品字段、品牌资料或比价。品牌概览只使用 Skill 内已审核的本地品牌知识；未收录品牌省略。工具没有的平台覆盖、评分、销量、实时到货时效等是工具侧限制，必须省略或明确未知，不编造。

## 5. 错误

单次 lookup 仍失败时，说明当前暂时无法解析链接或取得可靠商品详情，请用户重发完整链接、补充商品名称或稍后重试。不暴露命令、CLI、字段、参数、内部 ID、堆栈或服务细节。
