# 收货地址解析、确认与隐私规则

涉及查看收货地址列表、结算选地址，或创建/修改收货地址（包括服务返回 `region_selection_required: true`）时读取本参考。先确认目标 Agent 工具开放情况与会员授权；不要预先将地址能力降级为“只能手填”，确实不支持或无目录数据时再如实说明并用真实商城 H5 入口引导。

## 离线地区解析工具（`scripts/region_lookup.py`）

包内随附只读地区快照 `data/regions-prod.json`（默认生产环境 `prod`）与 `data/regions-pre.json`（仅明确切换到 `pre` 时使用），无需联网或调用后端 `/system/region/resolve`。`environment` 必须与当前实际连接环境一致，省略时读取 `defaults.json`（正式包为 `prod`）；不得跨环境混用地区 ID 或把 `pre` 快照改名为 `prod`。

通过标准输入传入单行 JSON，读取单行 JSON 输出：

```bash
python3 "<skill-dir>/scripts/region_lookup.py"
```

```json
{"environment":"prod","op":"prepare","address":"浙江省杭州市西湖区翠苑街道测试路1号"}
{"environment":"prod","op":"prepare","names":["福建省","厦门市","翔安区"],"detail":"测试位置1号"}
{"environment":"prod","op":"prepare","names":["浙江省","杭州市","西湖区","翠苑街道"],"detail":"测试路1号"}
{"environment":"prod","op":"children","parent_id":"0"}
{"environment":"prod","op":"children","parent_id":"<上级地区ID>"}
{"environment":"prod","op":"resolve","ids":["<省ID>","<市ID>","<区ID>"]}
{"environment":"prod","op":"resolve","names":["<省名>","<市名>","<区名>"]}
```

### 解析与澄清规则

1. **优先调用 `prepare`**：用户已提供省市区名称或整段地址时，直接调用 `prepare`，无需强迫用户从省开始逐级点选。
2. **简称与层级规则**：
   - 支持标准全称与去行政后缀简称（如“浙江省/浙江”“杭州市/杭州”“西湖区/西湖”），以及已知民族自治地方尾部后缀简称（如“延边/延边朝鲜族自治州”“长阳/长阳土家族自治县”），全称优先并校验真实父子关系；不猜错别字、不做任意子串匹配、不把“浙江市”臆测改成“浙江省”。
   - 地区固定输出省、市、区三级（`region_path` 与 `region_id_path`）；第四级街道/乡镇自动保留在 `detail` 前缀，不查第四级 ID。直辖市仅在唯一市节点下允许省略重复市名。
   - `address` 与 `detail` 不能同时传入；工具不剥离姓名或手机号前缀，也不根据上下文、IP 或默认项补全地区。
3. **边界歧义与缺项处理**：
   - 返回 `REGION_BOUNDARY_UNCLEAR`（如“浙江杭州西湖大学路1号”无法区分“西湖区+大学路”还是其他区县）时，请用户明确区县名称或补充分隔符，不擅自切分。
   - `detail_required: true` 表示缺少详细门牌或仅写到街道/乡镇，需请用户补充具体门牌位置。
   - 无法直接匹配时再用 `children` 按 `parent_id` 逐级列出候选供用户选择或输入，不隐瞒未列完的候选；某市在快照中无区县节点时说明目录限制，不虚构区县。
4. **确认后再写入**：拿到规范的 `region_path`、`region_id_path`、`detail` 后，连同收件人姓名和手机号向用户完整核对确认；仅在用户明确授权创建或修改地址后，将这三个规范字段放进同一 `conversation` 的下一条 `send` 请求交由托管 Agent 执行，不让模型手写或拼接地区 ID。若远端提示地区 ID 无效或过期，说明目录需更新并停止重试错误 ID。

## 地址列表展示与对话操作边界

- **单一可信快照**：列表仅展示本轮校验通过的一份快照（唯一有效结算快照优先；结算快照失效而地址簿有效时展示地址簿并注明“本次收货地址尚未核实”；多结算场景有歧义时先在对话中确认结算方式，不跨场景拼接选中标记）。
- **默认与本次选中独立**：`默认地址` 与 `本次已选中` 独立展示，不凭默认标记推断结算已选；选中地址不在当前页时如实说明。`unavailable` 表示状态待核实，不等于空地址簿。
- **编号时效与写后刷新**：列表序号仅对应最近一次实际展示给用户的列表；发生刷新、翻页、删除或场景切换后必须重新核对目标对象，不能沿用旧序号直接改删。写入结果未知时先查询确认，不重放写操作。

## 号码隐私与离线依赖

- 包内 `third_party/` 提供固定版本且校验 SHA-256 的离线 `phonenumberslite` 库（许可说明见 [../third_party/README.md](../third_party/README.md)），复制安装 Skill 时必须完整保留该目录，缺失或损坏会拒绝启动。
- 地址快照中的手机号仅接受 `138****1234` 脱敏格式；姓名、地区或详细地址字段若夹带完整电话号码会被拦截降级为不可用。自由文本中的完整号码（含国际区号、分机与 Unicode 数字）展示为 `[号码已隐藏]`，不得在回复中反推或复述完整号码。
